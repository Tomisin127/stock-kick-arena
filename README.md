# Stock Kick Arena

Onchain football that uses tokenized stocks as the ball



Build this onchain top down football game (the camera view is at the top directly) 



So there are two players(player 1 and player 2) or player can play with the computer.. 



Before the game starts the players lock in the select tokenized stocks they want to use to bet or play with (locked in a contract) .. Each players have 5 circle characters that they can move to kick the ball to the opponents goal post and every kick of a ball is a trsnaction the sends 0.000001$ worth of eth to the game creator address = (0x72110c7117Ee3D0BC77D4682107EA04b02312ED6), the player have in their wallet, use privy so the player signs in with email



The visuals of the game is like a filed where there are spectators sitted and watching and cheering like how "clash royale" game by supercell feels.. Start with Player vs computer mode for now
